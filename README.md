# Kasir Digital

Sinkron dengan Google Sheets lewat Apps Script.

1. Isi `src/config.ts` (URL /exec dan token).
2. Tempel `Code.gs` di Apps Script, jalankan `setup`, deploy Web App.
3. `npm install` lalu `npm run dev` untuk uji lokal.
4. Push ke GitHub (cabang main); Settings > Pages > Source: GitHub Actions.
